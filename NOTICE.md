DashLive v30 upstream Widgetify localization port.

This package uses and adapts the MIT-licensed Widgetify extension source from widgetify-app/widgetify-extension for the new-tab UI, animation system, widget visuals, and assets. Original license is included as LICENSE.widgetify. Runtime text has been localized to English and Iran-specific services have been replaced with globally usable US/EU-oriented alternatives.
