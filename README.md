# LiveDash

LiveDash is a local-first daily command center for time, weather, focus sessions, tasks, notes, search, quick links, bookmarks, habits, agenda blocks, quotes, and personal metrics.

## Run

```bash
npm install
npm run start
```

Open `http://localhost:5173`.

## Verify

```bash
npm run build
```

The project has no runtime package dependencies. Dashboard data is stored locally in the browser.
